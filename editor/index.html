Garden editor

Edit your garden notes here and see exactly how they'll look on the site. Saving commits the note to daphnepsy/garden, and it goes live a minute or two later.

To save, the editor needs a GitHub token that can change that one repo:

  1. Open GitHub → new fine-grained token.
  2. Name it “Garden editor” and pick an expiration.
  3. Under Repository access, choose Only select repositories → daphnepsy/garden.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate it and paste it below.

The token stays in this browser only. Use “Sign out” in the editor to remove it.
